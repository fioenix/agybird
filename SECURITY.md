# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Older versions | No |

## Report a vulnerability

Use GitHub's **Report a vulnerability** flow to open a private security advisory for this repository. Include the affected version, operating system, reproduction steps, impact, and a minimal proof of concept. Do not open a public issue for an unpatched vulnerability and do not include real Antigravity credentials or user data.

Maintainers will acknowledge a valid report through the private advisory, investigate it, and coordinate disclosure after a fix is available.

## Scope

Security issues in Agybird's runner, instructions, packaging, or workflows belong here. Authentication, subscription eligibility, provider permissions, and service behavior owned by Google should be reported through Google's channels. See the [official Antigravity overview](https://antigravity.google/docs/cli/overview) and [terms](https://antigravity.google/terms).
